行事曆－雲端帳號恢復最終版

這版修正：
- iPhone 刪除／重新加入主畫面後，不再遺失所屬行事曆設定。
- calendarCode、顯示名稱、顏色會存到 Firebase 使用者個人資料。
- 同一個 Email/密碼登入後會自動找回原本行事曆。
- 管理員舊資料若 members 欄位缺漏，會自動修復自己的成員權限。
- 保留人物 Icon、完整提醒、節日、多人同步等全部既有功能。

更新有兩個必要步驟：

一、GitHub
1. 解壓 ZIP。
2. GitHub → shared-calendar → Add file → Upload files。
3. 全部檔案與 icons 資料夾覆蓋上傳。
4. Commit changes。

二、Firebase 規則（一定要做）
1. Firebase Console → Firestore Database → 規則。
2. 把本 ZIP 裡 firestore.rules 的完整內容複製過去。
3. 按「發布」。

完成後：
iPhone 即使移除主畫面的行事曆再重新加入，只要登入相同帳號，就會自動恢復原本行事曆。
