GitHub 更新方式：
1. 解壓縮本 ZIP。
2. 進入 GitHub 的 shared-calendar repository。
3. Add file → Upload files。
4. 將解壓後的「所有檔案與 icons 資料夾」一起拖進上傳區。
5. 若出現同名檔案，讓新版覆蓋舊版。
6. 按 Commit changes。
7. 等待 GitHub Pages 約 1～3 分鐘更新。
8. iPhone 若仍顯示舊圖示／舊版本，先刪除主畫面舊捷徑，再由 Safari 重新「加入主畫面」。

注意：
GitHub Pages 不會自動解壓 ZIP，因此不能直接把 ZIP 本身當網站檔案上傳。
